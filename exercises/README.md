# Bonus Exercises

Practice what you learned with these hands-on exercises!

---

## Available Exercises

### [Exercise 1: Add a New Endpoint](exercise-1-add-endpoint.md)
**Difficulty:** Beginner  
**Time:** 20-30 minutes

Add a `/stats` endpoint that returns task statistics.

**You'll learn:**
- Adding new API endpoints
- Calculating statistics
- Writing tests for new features

---

### [Exercise 2: Add More Tests](exercise-2-add-tests.md)
**Difficulty:** Beginner  
**Time:** 30-40 minutes

Improve test coverage by adding edge case tests.

**You'll learn:**
- Testing error conditions
- Testing edge cases
- Improving code quality

---

### [Exercise 3: Fix a Broken Pipeline](exercise-3-fix-pipeline.md)
**Difficulty:** Intermediate  
**Time:** 20-30 minutes

Debug and fix a broken CI/CD pipeline.

**You'll learn:**
- Reading error logs
- Debugging pipeline failures
- Common CI/CD issues

---

## How to Use These Exercises

1. **Complete them in order** - They build on each other
2. **Take your time** - Understanding is more important than speed
3. **Experiment** - Try the bonus challenges!
4. **Ask for help** - Open an issue if you're stuck

---

## After Completing Exercises

- ✅ You'll have deeper understanding of CI/CD
- ✅ You'll be comfortable adding features
- ✅ You'll know how to debug issues
- ✅ You'll have more code to show employers!
