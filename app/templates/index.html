This UI is connected to your REST API! Every action you take calls an API endpoint:

  • Add Task: POST /tasks
  • Toggle Complete: PUT /tasks/:id
  • Delete Task: DELETE /tasks/:id
  • Load Tasks: GET /tasks

Open browser DevTools (F12) → Network tab to see API calls in action!
