# Hour 1: Local Development & Testing

**Goal:** Build and test a Flask app on your local machine

**Time:** 60 minutes (4 × 15-minute steps)

---

## What You'll Learn

By the end of Hour 1, you'll know how to:
- ✅ Understand a Flask application structure
- ✅ Run a web app locally
- ✅ Write and run automated tests
- ✅ Containerize an app with Docker

---

---

## Steps

### [Step 1: Understand the App](01-understand-the-app.md) (15 min)
**What:** Explore the Flask application code  
**Learn:** REST API endpoints, Flask routing, JSON responses

### [Step 2: Run Locally](02-run-locally.md) (15 min)
**What:** Get the app running on your machine  
**Learn:** Running Flask apps, testing with browser and curl

### [Step 3: Write Tests](03-write-tests.md) (15 min)
**What:** Write automated tests for the app  
**Learn:** pytest basics, unit testing, test coverage

### [Step 4: Docker Basics](04-docker-basics.md) (15 min)
**What:** Package the app in a Docker container  
**Learn:** Docker fundamentals, Dockerfile, containerization
